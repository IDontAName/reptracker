# Basgiath Honor Tracker — Group 2

Single-page NPC standing tracker for the second campaign group.

- **Site:** `index.html` (served by GitHub Pages from the repo root)
- **Backend:** Supabase project `dnd-action-tracker`, edge function `rep-api-g2`, tables `g2_accounts`, `g2_npcs`, `g2_scores`, `g2_sessions`
- `rep-api-g2/index.ts` is a reference copy of the deployed edge function. Editing it here does not redeploy it.

Completely separate from the original group's tracker (`rep-api` / `rep_*` tables).
